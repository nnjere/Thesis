What is it?

Bluesky is a social network built on an open system that anyone can build on. Its app is open source, so anyone can read how it works and propose changes.

In the sandbox you get a pretend timeline with test accounts, so nothing you do is posted for real. Turn features on and off, compare with the original, and share what you’d change.
